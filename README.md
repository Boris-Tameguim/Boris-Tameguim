# Cybersecurity Home Lab

Hands-on projects demonstrating entry-level SOC analyst and IT support skills.

## Objectives

This lab is designed to practice:

- Security monitoring and alert triage
- Windows and Linux administration
- Network traffic analysis
- Log analysis
- Identity and access management
- Help-desk ticket documentation
- Basic incident response

## Projects

### 1. Wazuh SIEM Lab

Built a virtualized security monitoring environment with Windows and Linux endpoints.

Skills practiced:

- SIEM deployment
- Agent installation
- Windows and Linux log ingestion
- Authentication-event monitoring
- Failed-login investigation
- Alert triage
- Incident documentation

[View the Wazuh project](./05-wazuh-siem/README.md)

### 2. Wireshark Network Analysis

Captured and analyzed authorized lab traffic.

Skills practiced:

- DNS analysis
- TCP three-way handshakes
- HTTP and TLS traffic
- PCAP investigation
- Baseline analysis
- Network troubleshooting

[View the Wireshark project](./02-wireshark/README.md)

### 3. Linux and Apache Web Server

Built and troubleshot an Apache web server on a Linux virtual machine.

Skills practiced:

- Linux command line
- Package management
- Service management with systemd
- Apache configuration
- Access and error-log analysis
- Troubleshooting permissions and configuration errors

[View the Linux project](./01-linux-apache/README.md)

### 4. Active Directory Lab

Created a fictional enterprise identity-management environment.

Skills practiced:

- User creation
- Organizational units
- Security groups
- Shared-folder permissions
- Access testing
- Least privilege

[View the Active Directory project](./04-active-directory/README.md)

### 5. osTicket Help-Desk Lab

Deployed a help-desk ticketing system with Docker.

Skills practiced:

- Ticket intake
- Priority assignment
- Troubleshooting documentation
- Escalation
- Resolution
